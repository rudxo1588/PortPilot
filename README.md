# PortPilot

현재 사용자의 TCP LISTEN 포트를 보고, 선택한 프로세스를 종료하는 작은 Mac 창 앱입니다. 외부 라이브러리, 네트워크 서비스, 관리자 권한 없이 AppKit·libproc·lsof를 사용합니다.

## 실행

아래의 소스 빌드 후 `Build/PortPilot.app`을 Finder에서 더블클릭하거나 다음 명령을 실행합니다.

```sh
open ./Build/PortPilot.app
```

`run.command`도 같은 앱을 엽니다. 이 빌드는 Apple Silicon용이며 macOS 14 이상을 대상으로 합니다. Apple 개발자 배포 서명과 공증은 없습니다. 실행 제한이 표시되면 보안 설정을 바꾸거나 우회하지 마세요.

배포용 `Dist/PortPilot-macOS-arm64.zip`은 깨끗한 임시 번들에서 로컬 ad hoc 서명 후 생성하며, 재추출한 앱의 엄격 서명 검증을 확인했습니다. 이 Mac의 Documents 작업폴더는 File Provider가 앱 폴더에 Finder 메타데이터를 추가해 직접 번들의 엄격 검증을 실패시킬 수 있습니다. ZIP을 일반 로컬 앱 폴더에 풀어 사용하세요. 해당 메타데이터나 보안 속성을 강제로 삭제하지 않습니다.

## 사용

CPU와 메모리 패널에서 전체·사용·여유 자원과 사용량 상위 프로세스 3개를 확인합니다. 포트 목록에서 CPU·메모리·실행 시간 열 머리글을 클릭하면 정렬 방향을 바꿀 수 있습니다. 프로젝트가 식별되면 프로세스명 옆에 이름을 표시합니다. 이름 위에 포인터를 올리면 경로를 볼 수 있고, 검색창에서 프로젝트명 또는 경로를 찾을 수 있습니다.

1. **새로고침**으로 현재 포트를 확인합니다. 기본 체크 선택은 비어 있습니다.
2. 검색 또는 **Java / 개발 프로세스** 필터로 후보를 좁히고 PID·소유자·앱 식별자를 확인합니다. 필터에는 IDE와 빌드 도구도 포함될 수 있습니다.
3. 필요한 포트의 행이나 체크박스를 클릭하고 **선택 종료…**를 누릅니다. 확인창에는 선택 PID가 가진 전체 포트와 시작 시간이 표시됩니다. 프로세스를 종료하면 그 PID의 다른 작업도 함께 종료됩니다.
4. **일반 종료(SIGTERM)** 후 최대 4초 기다립니다. 같은 PID는 한 번만 처리합니다.
5. 응답하지 않은 대상만 **강제 종료…**가 활성화됩니다. **취소**가 기본인 별도 확인창에서 SIGKILL을 승인해야 강제 종료합니다.
6. 아래 결과 영역에서 대상별 결과와 포트 해제 확인을 봅니다. 필터·검색·새로고침을 변경하면 체크 선택을 지웁니다.

선택한 행의 포트 번호는 **선택 포트 복사**로 복사할 수 있습니다.

## 안전장치

- 현재 사용자와 실제·유효·저장 UID가 모두 일치하는 프로세스만 허용합니다. root, 시스템 프로세스, 다른 사용자, 앱 자신은 막습니다.
- 목록에서 얻은 PID·시작 시각(마이크로초)·UID·실행 파일·PID 세대를 다시 확인합니다.
- 종료 직전에 대상 PID의 전체 LISTEN 주소/포트 집합도 비교합니다. 목록이 바뀌거나 신원 확인이 실패하면 신호를 보내지 않습니다.
- 신호는 `proc_signal_with_audittoken`으로 PID 세대를 커널에서 확인합니다. 일반 `kill(pid, signal)`로 후퇴하지 않습니다.
- 일반 종료 후에도 같은 프로세스와 원래 전체 포트가 남아 있는 경우에만 강제 종료 후보로 유지하며, 강제 종료 직전 다시 검증합니다.
- 전체 명령줄이나 환경변수를 UI·로그·파일로 내보내지 않습니다. Java 실행 인자는 메모리에서 제한적으로 읽고, 허용된 메인 클래스 또는 JAR 파일명만 표시합니다. 모듈·argfile·알 수 없는 옵션은 식별하지 않습니다.
- 설정, 자동 실행, 지속 권한을 추가하지 않습니다. TCP LISTEN 정보만 다루며 UDP는 표시하지 않습니다. 운영체제 접근 제한으로 다른 사용자의 일부 프로세스는 표시되지 않을 수 있습니다.

PID 세대는 공개 API `task_name_for_pid`와 `TASK_AUDIT_TOKEN`의 읽기 전용 권한으로 확인하며 조회 직후 해제합니다. 제어 권한이나 별도 entitlement를 요청하지 않습니다. 신원을 확인할 수 없는 대상은 종료를 차단합니다. [Apple XNU의 감사 토큰 처리](https://github.com/apple-oss-distributions/xnu/blob/xnu-10063.141.1/osfmk/kern/task.c)와 [신호 처리 구현](https://github.com/apple-oss-distributions/xnu/blob/xnu-10063.141.1/bsd/kern/proc_info.c)을 기준으로 작성했으며, 이 Mac(macOS 14.8.2)에서 검증했습니다. 이후 macOS에서의 호환성은 별도 확인이 필요합니다.

## 소스에서 빌드

이미 설치된 Apple Command Line Tools의 Swift·clang만 필요합니다.

```sh
./build.sh
./run.command
```

`Sources/main.swift`는 AppKit 창, `Sources/PortCore.swift`는 목록과 종료 흐름, `Sources/ProcessBridge.c`는 프로세스 신원과 PID 세대 확인을 구현합니다. `Tests`에는 직접 만든 루프백 리스너와 검증 코드가 있습니다. 테스트는 테스트 코드가 만든 PID에만 신호를 보냅니다.

`Resources/generate-icon.swift`는 포트·연결을 형상화한 아이콘의 벡터 원본입니다. 빌드할 때 AppKit으로 16~1024픽셀 PNG와 `PortPilot.icns`를 다시 만들고 앱에 포함합니다. `Resources/PortPilot-icon-preview.png`에서 큰 아이콘과 작은 크기의 미리보기를 볼 수 있습니다. 앱 전체에 로컬 ad hoc 서명을 적용하고 리소스 무결성을 검증합니다. Developer ID 서명·공증은 포함하지 않습니다.

## 검증

저장소 루트에서 `./Tests/run_tests.sh`를 실행합니다. 테스트는 전용으로 생성한 리스너와 프로세스를 사용합니다.
